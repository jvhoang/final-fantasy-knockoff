# Stack Decision — Final Fantasy Knockoff

**Winner:** Web-native ES modules + Three.js + Node WebSocket (optional for multiplayer).

## Why

1. Browser-first deploy (GitHub Pages static client + optional Node server)
2. Pure CT/path/loadout logic unit-testable with `node --test`
3. Three.js isometric presentation without Unity/Godot install

See README for run and Pages deploy.
